# Breast-Cancer-Dataset
In this project, I implemented a binary classification model using Logistic Regression.
The dataset was first cleaned by dropping the Unnamed: 32 column, which contained only null values, and the id column, which had no predictive significance. The target column diagnosis, labeled as 'M' and 'B', was encoded into binary values (1 for malignant and 0 for benign) to suit the classification model.
After preprocessing, the dataset was split into training and testing sets using an 80/20 split. The feature values were then standardized using scikit-learn's StandardScaler to ensure all features contributed equally to the model's performance. I trained a Logistic Regression model using scikit-learn and evaluated its performance using a variety of metrics including the confusion matrix, precision, recall, F1-score, and ROC-AUC score. Additionally, I visualized the model's ROC curve to analyze its ability to separate the two classes.
An important aspect of this project was threshold tuning, where I adjusted the classification threshold to observe how the model's sensitivity (recall) and specificity (precision) changed.
This repository includes the Breast Cancer Dataset.ipynb containing the full implementation, the dataset file, and this README file explaining the steps taken. The project also emphasizes the importance of proper preprocessing, model evaluation, and interpretation of results.
